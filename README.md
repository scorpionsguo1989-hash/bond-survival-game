# 债市生存游戏 (Bond Survival Game)

单页面债券市场生存模拟游戏。

## 技术栈

- 纯前端：ES modules + CDN Chart.js
- 测试：Vitest
- 无构建工具

## 开发

```bash
npm install        # 安装依赖
npm test           # 运行测试
npm run test:watch # 监听测试
npm run serve      # 启动本地服务器（http://localhost:8080）
```

## 项目结构

```
js/         游戏逻辑模块
css/        样式
content/    游戏内容（JSON）
tests/      单元测试
docs/       设计文档
```
