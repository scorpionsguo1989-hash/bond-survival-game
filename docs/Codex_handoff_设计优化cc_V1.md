## 项目背景

### 游戏简介

《债市生存游戏》是面向中国债券市场从业者（券商/银行/资管 DCM 群体）的策略游戏，发布在用户的"搞债"公众号上。

**3 角色**（命运卡随机分配）：
- **CFO**（城投财务总监）—— 发债方视角，管现金流和债务到期
- **IM**（债券基金经理）—— 买债方视角，管 NAV 和赎回压力
- **GOV**（地方政府官员）—— 监管+担保视角，管财政和化债

**节奏**：12 季度（2022Q1 - 2024Q4），每季度面对：
- 1 个主线事件（基于真实历史，3 选项）
- 0-2 个随机事件
- 最多 2 次主动操作（每角色 5 种操作）
- 危机模态框（极端情况触发）

**终局**：六维雷达图评分 + 全球排行榜（按角色筛选）+ 可分享 PNG 卡片。

### 现有美学（要保留）

- **深色金融终端风格**：背景 #0a0e1a，主色 #4fc3f7（青蓝）
- **SF Mono 等宽字体**，模仿彭博/Wind 终端
- **关键色**：cash 绿/黄/红三色预警，grade S/A/B/C/D 各有专属色
- **角色专属色**（建议加强）：CFO 青蓝 / IM 金黄 / GOV 朱红

### 痛点（要优化）

1. 字号偏小（11-12px），层级不清晰
2. 原生 `prompt()` 输入操作金额（丑+移动差）→ 改自定义 Modal
3. 原生 `alert()` 弹窗反馈（打断流程）→ 改 Toast
4. 桌面三栏布局在手机崩 → 响应式
5. 缺少状态过渡动画
6. 图表配色与指标卡风格不统一

### 设计原则

- ✅ 保留深色金融终端美学（不改成 SaaS 浅色）
- ✅ 强化信息密度（金融用户习惯高密度数据）
- ✅ 优化移动端（公众号读者大概率手机看）
- ❌ 避免过度动画 / 过度装饰 / 卡通图标（要专业感）

### Round 3 · 弹层组件（Modal / Toast / 危机框）

【对 Claude Design 说】

```
请设计 3 类弹层组件，沿用 Round 0 中的暗色金融终端风格：

【1. 操作输入 Modal（替代原生 prompt）】
触发场景：玩家点"申请银行续贷"按钮，需要输入金额（0.5-5 亿）

要素：
- 标题：操作名（如 "申请银行续贷"）
- 描述：操作 desc 一句话
- 输入字段：数字 input + label（如 "借款金额（亿）"，min/max 提示）
- 滑动条（可选，让玩家拖动选金额）
- 副信息：💡 预计影响（这次操作会让 cash +X / creditUsed -Y）
- 双按钮：取消 / 确认

【2. Toast 通知（替代原生 alert）】
3 种 variant：
- success（绿色边框 + 勾号）：用于"处置成功"
- error（红色边框 + 叉号）：用于"处置失败" / 数据校验失败
- info（青蓝色边框 + i 号）：用于"已自动保存" / "提交成功，排名 #X"

要素：
- 右上角浮出（桌面）/ 顶部下拉（移动）
- 自动 3 秒消失，可手动关闭
- 单行或双行文案

【3. 危机模态框（已有，但需要重设计）】
触发场景：
- CFO 现金 < 0.5 亿
- IM 赎回压力 ≥ 80
- GOV 隐债敞口 > 200 亿

视觉特点：
- 全屏遮罩（半透明深红）
- 顶部红色 banner "⚠ 危机警报 · 时间暂停 · 必须处置后继续"
- 主卡片：
  * 标题 + 描述
  * 3 个关键指标（label + value）
  * 3 个处置选项（每个有 label + 代价标签 + desc + effects 预告）
- 选项卡片要有"分量感"（不是普通按钮，是"需要慎重选择"的视觉感）

【输出要求】
3 个组件，每个给桌面 + 移动 2 个版本。
危机模态框的"红色紧迫感"要做出来，不能是普通弹窗。
```

## 兜底情况

### 如果 Claude Design 桌面端无法直接交互

把每轮 prompt 输出到屏幕，告诉用户：

```
[Round X] 请手动复制下方 prompt 到 Claude Design 网页端（claudedesign.com 或类似），
拿到设计后把图片存到 docs/design_outputs/images/roundX/，
设计说明粘贴回来，我帮你归档。
---
[Round X 的 prompt 内容]
```

### 如果 Claude Design 输出代码（React/Tailwind）

完整保存代码到 `docs/design_outputs/code/roundX/`，但**不要尝试落地**——Claude 会把它转译到 vanilla JS + 手写 CSS。

### 如果 5 轮跑下来发现某轮质量很差

记录下来，标注 `[需要 Claude 重新设计]`，由 Claude 决定是否要二次出图。
