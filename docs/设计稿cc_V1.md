# 债市生存游戏 · 设计文档

> 版本：cc_V1 · 2026-04-29

---

## 一、项目概述

面向"搞债"公众号读者群体的债券市场生存模拟游戏。玩家随机获得身份和平台，在2022-2024年化债背景下做决策，目标是活过3年并获得尽可能高的综合评分。

**核心体验**：叙事+策略混合。大事件用剧情文字+选项呈现，面板实时反映后果；玩家也可主动操作。从业者感受真实感，普通读者感受故事张力。

---

## 二、技术架构

**部署**：轻量云服务器（已有），nginx反向代理

**前端**：多文件静态站
```
/game/
├── index.html
├── js/
│   ├── engine.js      # 游戏状态机：回合推进、指标计算、胜负判断
│   ├── events.js      # 事件库：主线事件 + 随机事件池
│   ├── roles.js       # 角色配置：三套参数、约束、操作定义
│   └── charts.js      # Chart.js图表层
├── css/style.css
└── api/
    ├── server.js      # Node.js + Express
    └── leaderboard.db # SQLite排行榜
```

**后端**：Node.js + Express，仅负责排行榜读写
**数据库**：SQLite，文件型，零配置
**图表**：Chart.js（CDN引入）
**视觉风格**：Bloomberg终端暗色风，深色背景+红绿指标

## 三、角色系统

### 3.1 三个角色

| 角色 | 核心压力 | 死亡条件 |
|------|---------|---------|
| 城投财务总监 | 现金断流、兑付压力 | 现金归零 / 兑付违约 |
| 投资经理 | 净值下跌、赎回压力 | 净值跌穿预警线 / 赎回潮流动性枯竭 |
| 地方官员 | 债务失控、政治压力 | 债务失控被约谈 / 隐债核查爆雷 |

### 3.2 角色A：城投财务总监

**核心指标**：现金余量、债务到期日历、综合融资成本、授信使用率、资产负债率、运营成本消耗率、在建项目投资缺口、抵押物剩余空间

**现金优先级**：金融市场兑付 > 运营成本 > 项目投资

**约束条件**：授信额度上限、融资成本红线、监管债务率红线、抵押物上限、监管政策变化（银行收紧/发债窗口关闭）

**主动操作**：银行贷款/续贷、发行城投债、提前备款、申请政策性银行支持、资产处置变现、非标融资（高成本高风险）

### 3.3 角色B：投资经理

**核心指标**：组合净值、持仓集中度、流动性比例、信用风险敞口、收益率（vs benchmark）、赎回压力指数

**约束条件**：总仓位上限、单券集中度≤15%、现金比例≥10%、久期限制、监管政策（评级门槛/集中度新规）、市场流动性冻结风险、持有人赎回压力

**主动操作**：买入/卖出债券、调整久期、回购加杠杆、规避高风险主体、向持有人管理预期

### 3.4 角色C：地方官员

**核心指标**：财政收入、土地出让收入、地方债务率、城投信用状况、产业发展指数、政绩评分、隐性债务化解进度

**约束条件**：债务率红线300%、土地出让年度上限、财政不能长期赤字、不能违规举债、化债任务指标、土地市场低迷风险、转移支付不稳定

**主动操作**：招商引资、申请专项债额度、城投整合重组、土地收储出让、向上争取转移支付、隐性债务置换、牺牲产业投资换短期财政平衡

## 四、开局随机系统

### 4.1 随机维度

**角色A（财务总监）**

| 维度 | 选项 |
|------|------|
| 区域能级 | 东部核心城市 / 中部省会 / 西部地级市 / 东北老工业区 |
| 平台主业 | 基础设施建设 / 土地一级开发 / 产业园区运营 / 公用事业 |
| 财务健康度 | 健康 / 一般 / 承压 |
| 特殊标签 | 明星平台 / 隐债重灾区 / 有省级增信 / 领导班子刚换 / 正在整合重组 / 优质资产注入预期 |

**角色B（投资经理）**

| 维度 | 选项 |
|------|------|
| 机构类型 | 银行理财 / 公募基金 / 保险资管 / 私募基金 |
| 管理规模 | 大规模（子弹多但考核严）/ 中规模 / 小规模（灵活但压力大） |
| 持仓健康度 | 干净 / 有几个问题券 / 重仓弱资质主体 |
| 特殊标签 | 新发产品建仓期 / 面临大额赎回压力 / 刚经历净值回撤 / 明星基金经理光环 / 机构客户集中度高 / 即将考核节点 |

**角色C（地方官员）**

| 维度 | 选项 |
|------|------|
| 城市能级 | 强省会 / 普通地级市 / 县级市 / 资源型城市 |
| 财政状况 | 自给率高 / 依赖转移支付 / 土地财政高度依赖 |
| 政治背景 | 新官上任 / 即将换届 / 长期执政稳定 / 空降干部 |
| 特殊标签 | 重大项目在建 / 被列为化债重点区域 / 有央企战略合作 / 土地纠纷遗留 / 产业转型阵痛期 / 人口持续流出 |

### 4.2 平衡机制

- 系统随机后内部校验总挑战值是否在目标区间，不在则重抽（玩家不可见）
- **非对称平衡**：强平台压力来自合规/政治，弱平台压力来自资源匮乏，总体通关率相当
- 开局展示"命运卡"：角色身份 + 平台画像 + 三大挑战提示

## 五、游戏循环

### 5.1 标准回合（每季度）

```
1. 政策轴漂移（+1/-1）→ 更新政策信号灯
2. 收入/到期债务自动结算
3. 随机支线事件抽取（0-2个）
4. 玩家主动操作（每回合最多2次）
5. 指标更新 + 图表刷新
6. 检查死亡条件
7. 进入下一季度
```

### 5.2 胜负条件

- **硬失败**：核心指标触底（现金归零/净值穿线/被约谈）
- **通关**：存活至2024年Q4
- **评分**：通关后出六维雷达图评分，入排行榜
  - 六个维度：流动性管理 / 融资成本控制 / 项目推进 / 合规指数 / 危机应对 / 综合发展（各角色同维度，权重不同）

### 5.3 游戏时长

- 标准局：3年 = 12回合
- 每回合预计2-4分钟决策时间
- 单局总时长约20-30分钟

## 六、政策环境系统

全局共享变量，三个角色同时面对。

**政策轴**：`[-5 极紧] ←→ [0 中性] ←→ [+5 极松]`

| 触发方式 | 说明 |
|---------|------|
| 季度漂移 | 每季度向当前方向小幅移动（±1） |
| 主线事件 | 触发方向性转折（如化债政策出台，轴值大幅跳升） |
| 随机支线 | 在当前方向上加速或短暂扰动 |

**玩家可见信息**：政策信号灯（宽松/中性/偏紧/严格）+ 趋势箭头。可预判趋势，但不能精确知道下一步。

**各角色受影响方式**：
- A：轴越紧，发债窗口越窄，银行授信越难，非标监管越严
- B：轴越紧，信用利差走阔，持仓估值下跌，赎回压力增大
- C：轴越紧，隐债核查越频繁，专项债额度越难争

## 七、事件系统

### 7.1 主线事件（固定节点，约12个）

| 时间 | 主线事件 |
|------|---------|
| Q1 2022 | 开局：银行收紧城投贷款，发债审批趋严 |
| Q3 2022 | 某省城投爆雷，市场情绪骤冷，信用利差走阔 |
| Q4 2022 | 理财赎回潮，流动性危机蔓延 |
| Q1 2023 | 化债政策信号释放，政策轴开始转向 |
| Q3 2023 | 一揽子化债方案出台，专项债扩容 |
| Q1 2024 | 非标全面收紧，监管新规落地 |
| Q2 2024 | 城投整合提速，弱平台面临被并购压力 |
| Q3 2024 | 利率持续下行，再融资成本全面改善 |
| Q4 2024 | 终局结算，综合评分出炉 |

> 注：以上为已确认的9个主线节点，剩余3个节点在内容开发阶段补充。主线事件固定推进，但冲击强度由开局平台配置决定，强平台弱平台体感不同。

### 7.2 随机支线事件池

| 类型 | 事件示例 |
|------|---------|
| 市场类 | 利率突变、信用利差走阔、某主体评级下调、市场流动性冻结 |
| 经营类 | 重大项目超支、应收款无法回收、关联方出问题、承包商催款 |
| 政策类 | 窗口指导、检查组进驻、额度临时收紧/放开 |
| 机遇类 | 优质项目窗口、低息置换机会、政策性银行主动对接、优质资产注入 |

### 7.3 危机特殊回合

当任一核心指标触及红线，时间暂停，弹出危机处置界面：
- 红色警报视觉效果
- 限时选项（4个以内），每个选项标注代价等级（低/中/高）
- 选择后立即结算后果，继续游戏
